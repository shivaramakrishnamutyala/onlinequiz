Run test cases:

Open CMD, navigate to your project folder, then run:

Step 1 — go to the project folder

cd C:\Users\ADMIN\Desktop\onlinequiz
Step 2 — choose what you want to run

Run all tests (simple):

python -m pytest
Run all tests with verbose output (see each test name):

python -m pytest -v
Run all tests with coverage report:

python -m pytest -v --cov=. --cov-report=term-missing
Run a single test file:

python -m pytest tests/test_scoring_service.py -v
Run a single test by name:

python -m pytest tests/test_scoring_service.py::TestDetailedScoring::test_all_correct -v
